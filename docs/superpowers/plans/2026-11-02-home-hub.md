# Home Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Ireland-only root page with a static sectioned quiz hub at `/`, with Ireland available only via `/ireland`.

**Architecture:** Static HTML hub in `index.html`, styles in existing `src/style.css` using current design tokens. Delete the standalone Ireland quiz entry (`src/main.ts`, `src/map.ts`). Pack and Globle routes unchanged.

**Tech Stack:** Vite multi-page static site, plain HTML/CSS, Fraunces + Nunito, existing CSS variables.

## Global Constraints

- Preserve Fraunces + Nunito and paper/ink CSS variables from `src/style.css`
- Hub is static HTML with little or no JS
- Hardcode four quiz links (no registry)
- Keep `src/counties.ts` (Ireland pack depends on it)
- No redirect from `/` to `/ireland`
- No redesign of quiz pages

## File map

| File | Responsibility |
|------|----------------|
| `index.html` | Hub markup (replaces Ireland quiz page) |
| `src/style.css` | Add `.home` / directory row styles |
| `src/main.ts` | Delete (root quiz only) |
| `src/map.ts` | Delete (`IrelandMap` unused after root quiz removal) |
| `vite.config.ts` | No change required (`main` still points at `index.html`) |
| `vercel.json` | No change required |
